# Dataset and asset attribution

Application code and the underlying data have separate licenses.

- **OpenStreetMap contributors**: OSM-derived walking and place data, including the extract in `data/source/` and the OSM-derived parts of `public/data/transit.json`, are made available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Attribution: © OpenStreetMap contributors, https://www.openstreetmap.org/copyright. Preserve source/derivation notices when redistributing. The extract contains an adapted database and retains ODbL rights and conditions.
- **511 SF Bay / Metropolitan Transportation Commission**: Wheels schedule data provided by 511.org, via the Caltrans Cal-ITP public analysis copy. Preserve the visible attribution **data provided by 511.org** linked to https://511.org. Terms: https://511.org/sites/default/files/pdfs/511_Data_Agreement_Final.pdf.
- **Caltrans**: Cal-ITP GTFS-Ingest Pipeline Dataset, published under Creative Commons Attribution in the California open-data catalog. https://data.ca.gov/dataset/cal-itp-gtfs-ingest-pipeline-dataset.
- **BART**: Official BART GTFS data. https://www.bart.gov/schedules/developers/gtfs. Follow BART's linked developer license; BART marks and official system-map artwork are not included.
- **U.S. Census Bureau / Esri**: ACS 2020–2024 5-year household vehicle-availability estimates, table B08201, and the associated public boundary service. https://www.arcgis.com/home/item.html?id=458ceeeff7e847af8257ad5ce58e0161.
- **Map tiles**: © OpenStreetMap contributors. https://operations.osmfoundation.org/policies/tiles/. Tiles are requested interactively and are not bundled or bulk-downloaded by the app.
- **Fonts**: DM Sans and Manrope from Google Fonts, under their respective SIL Open Font Licenses. The CSS includes system-font fallbacks.
- **Icons and libraries**: Lucide icons (ISC); Leaflet (BSD-2-Clause); React (MIT). See the installed packages for complete notices.

The MIT license for this project's application code does not relicense these source datasets or third-party assets.
